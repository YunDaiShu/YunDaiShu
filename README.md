## 我在做的事

### [MkDownPost · 码稿](https://github.com/YunDaiShu/MkDownPost)

面向公众号 / 小黑盒 / TapTap / 知乎创作者的 Markdown 写作与排版工作台。

- 零构建（无打包器、无 node_modules）、纯静态、GitHub Pages 托管
- 100 套主题、9 个平台适配、8 种导出（含 PDF / Word / PNG）
- 81 篇 Markdown 实战文章，含可被搜索引擎收录的静态页
- 离线可用（Service Worker），不使用任何 AI 功能

[在线试用](https://yundaishu.github.io/MkDownPost/) · [文章列表](https://yundaishu.github.io/MkDownPost/#/articles) · [RSS](https://yundaishu.github.io/MkDownPost/feed.xml)

## 我做事的几条原则

| 原则 | 具体做法 |
| --- | --- |
| 数据在用户手里 | 不做账号、不做云同步、草稿只存本机 |
| 能用纯静态就别上后端 | GitHub Pages 足够就不引服务器 |
| 依赖本地化 | 第三方库全部 vendor 进仓库，运行时不请求外部 CDN |
| 性能是功能的一部分 | 首屏内联关键 CSS、按需加载、路由预取 |
| 承认边界 | 做不到的事写进 README，而不是含糊带过 |
