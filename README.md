## 我做事的四条原则

> **数据在用户手里** — 不做账号、不做云同步，草稿只存本机 localStorage。
>
> **能用纯静态就别上后端** — GitHub Pages 足够时，就不引服务器。
>
> **依赖本地化** — 第三方库全部 vendor 进仓库，运行时不请求外部 CDN。
>
> **承认边界** — 做不到的事写进 README，而不是含糊带过。
